1
Base visual: HTML, CSS y tu primera web
fundamentos + portafolio publicado
Meses 1–2
◆
victoria al terminar esta fase Tendrás una página web real con tu nombre, publicada en internet con una URL propia. No es un ejercicio, es real y la puedes mostrar a cualquiera hoy mismo.
Semanas 1–2
HTML: la estructura
Aprende a pensar en bloques. Cada elemento es una caja. Tu background de diseño ya entiende esto instintivamente.
headingsdivslistaslinks
Semanas 3–4
CSS: la forma visual
Colores, tipografía, espaciado. Tu ojo de diseñador te da una ventaja real aquí sobre el 90% de principiantes.
flexboxcoloresfuentesbox model
Semanas 5–6
Proyecto: portafolio v1
Una página con tu foto, tus proyectos de com. visual y una descripción. Simple pero completamente tuya.
layoutresponsiveGitHub Pages
Semanas 7–8
Git + publicar en internet
Versiona tu código y publica tu portafolio. Al terminar esta semana tendrás una URL real en internet.
git básicoGitHubdeploy
⚡

Ritmo recomendado: bloques de 25 min + 5 min de pausa. Construye algo cada sesión aunque sea pequeño. Ver tu web cambiar en vivo es el estímulo que necesitas para seguir.

2
Frontend real: JavaScript + interactividad
lógica + DOM + primera mini-app
Meses 3–4
◆
victoria al terminar esta fase Tu web reacciona cuando el usuario interactúa. Tienes al menos una mini-app publicada: un generador de colores, una calculadora, algo que responde y se mueve.
Semanas 9–10
JavaScript: la lógica
Variables, funciones, condicionales. No lo memorices: úsalo inmediatamente para hacer que tu web haga algo útil.
variablesfuncioneseventos
Semanas 11–12
DOM: manipula tu página
Aprende a cambiar cualquier cosa de tu web con código. Aquí la magia se vuelve completamente visible.
querySelectorclick eventsanimaciones
Semanas 13–14
APIs públicas: datos reales
Conecta tu web a datos del mundo exterior: clima, imágenes, colores. Aquí empieza lo verdaderamente emocionante.
fetchasync/awaitJSON
Semanas 15–16
Proyecto: mini-app visual
Combina tu habilidad visual con JS. Un generador de paletas, un explorador tipográfico, algo que use tu ojo de diseñador.
proyecto realCSS + JSpublicado
⚡

Mejor recurso para esta fase: javascript.info o The Odin Project. Tienen ejercicios integrados donde ves el resultado inmediatamente. Evita tutoriales de más de 20 minutos sin práctica activa.

3
Fullstack: React + backend básico
React · Node.js · base de datos · app completa
Meses 5–9
◆
victoria al terminar esta fase Tienes una aplicación web completa: frontend en React, backend con Node.js, base de datos, y usuarios que pueden registrarse. Tu primer producto real.
Mes 5
React: componentes
React es HTML con superpoderes. Aprende a pensar en piezas reutilizables, como si fueran componentes de un sistema de diseño.
componentesuseStateprops
Mes 6
Node.js + Express
El backend es el servidor invisible detrás de toda app. Aprende a crear endpoints que tu frontend pueda llamar.
rutasAPIs RESTJSON
Mes 7
Base de datos
SQL básico. Aprende a guardar y recuperar datos. Sin esto, tu app olvida todo cuando la recargas.
SQLCRUDSupabase
Meses 8–9
Proyecto fullstack completo
Un generador de portafolios, una plataforma de proyectos de diseño, un SaaS mínimo. Algo que te importe construir.
authdeployVercel
⚡

Esta es la fase más larga. Cada mes tiene su mini-proyecto para que nunca pases más de 2 semanas sin ver resultados. Si te atascas más de 2 días en algo, usa Claude para desbloquearte y sigue adelante.

4
IA integrada: tu ventaja competitiva
APIs de LLMs · RAG · producto con IA propio
Meses 10–14
◆
victoria al terminar esta fase Tienes al menos un producto con IA funcionando y publicado: un chatbot sobre documentos, un generador creativo, o una herramienta que usa LLMs. Esto ya es vendible.
Meses 10–11
APIs de IA
Aprende a integrar Claude, OpenAI u otros desde tu backend. Un prompt bien construido ya es el núcleo de un producto.
API callsprompt engineeringstreaming
Mes 12
RAG básico
Haz que la IA responda sobre documentos específicos. Es la tecnología detrás de la mayoría de herramientas B2B de IA.
embeddingsvectorescontexto
Meses 13–14
Tu herramienta IA propia
Diseño + código + IA. Un generador de branding, un asistente de diseño, un analizador de portafolios. Algo que nadie más tiene.
producto completoUX con IApublicado
⚡

Aquí tu background de comunicación visual es una ventaja enorme. Sabes qué hace que una experiencia con IA se sienta bien o mal. La mayoría de devs no tienen ese ojo y se nota.
